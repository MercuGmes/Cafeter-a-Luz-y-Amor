# ☕ Luz y Amor — Cafetería

Sitio web oficial de **Luz y Amor**, una cafetería costarricense creada alrededor del café, la calidez y los pequeños detalles.

La página fue diseñada para transmitir la identidad de la cafetería desde el primer momento, utilizando una estética artesanal, elegante y cálida, acompañada de animaciones y pequeñas interacciones.

## ✨ Características

- Diseño editorial y personalizado
- Experiencia responsive para móvil, tablet y escritorio
- Menú digital organizado por categorías
- Sección de **Menú Secreto**
- Galería de fotografías
- Animaciones y microinteracciones
- Efectos de scroll y transiciones suaves
- Diseño inspirado en la identidad visual de Luz y Amor
- Optimización para dispositivos móviles
- Sin backend ni base de datos
- Compatible con GitHub Pages

## 🍰 Secciones

### Inicio
Presentación de la cafetería con una introducción visual y acceso al menú.

### Nuestra esencia
Una sección dedicada a la filosofía y concepto de Luz y Amor.

### Menú
Incluye:

- Cafés
- Bebidas especiales
- Repostería
- Sándwiches y más
- Extras

### 🔐 Menú Secreto

Una experiencia especial dentro de la página.

El visitante puede descubrir bebidas que no aparecen en el menú tradicional, como:

- Poción de Amor
- Café de los Sueños
- Abrazo en Taza
- Beso de Fresa
- Nube de Vainilla
- Elixir de Energía

### 📸 Galería

Espacio visual para mostrar la cafetería, sus productos y diferentes momentos de la experiencia.

### ❤️ Filosofía

Frases y elementos visuales relacionados con la identidad de la marca:

> "En Luz y Amor, el ingrediente secreto siempre eres tú."

## 🛠️ Tecnologías

El proyecto está construido utilizando tecnologías web estándar:

- HTML5
- CSS3
- JavaScript
- SVG
- GitHub Pages

No requiere servidor, base de datos ni backend.
