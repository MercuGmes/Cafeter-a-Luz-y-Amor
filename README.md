# Luz y Amor — Cafetería

Sitio estático de Luz y Amor, cafetería costarricense.

## Estructura
- `index.html` — página completa (HTML, CSS y JS)
- `images/` — fotografías del sitio

## Publicar con GitHub Pages
1. Sube estos archivos a un repositorio en GitHub.
2. Ve a Settings → Pages.
3. En "Source" selecciona la rama `main` y la carpeta `/ (root)`.
4. Guarda. El sitio quedará disponible en `https://<tu-usuario>.github.io/<nombre-repo>/`.
